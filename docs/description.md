# Trivia App

Trivia App is a live, multiplayer quiz game. A host runs a quiz and players compete against each other in real time from their own phones, wherever they are. Everyone sees the same question at the same moment, races the same clock, and watches the scoreboard change as answers come in.

## Who uses it

- **Host.** The person running the quiz. The host creates a game, picks or writes the questions, invites players, and controls the pace: when the game starts, when to move to the next question, and when it ends.
- **Players.** Everyone taking part. Players join the host's game, answer each question as it appears, and compete for the top spot on the leaderboard.

## How a game works

1. **The host creates a quiz.** They choose the questions and answer options and set how long players get for each question.
2. **Players are invited.** The host shares an invite link. Opening it takes a player straight into that game's waiting room. There's no long sign-up.
3. **The waiting room.** Everyone can see who has joined and how many people are playing. When a player joins or drops out, the list updates straight away for everyone.
4. **The host starts the game.** The first question appears on every player's screen at the same time.
5. **Answering against the clock.** Each question has a countdown. The timer is the same for everyone, so no player gets more time than another. Players pick an answer before time runs out. When the timer ends, answers lock.
6. **Reveal and scoring.** The correct answer is shown. Players get points for answering correctly, and faster correct answers earn more points.
7. **Live leaderboard.** Scores update as answers arrive, so the host and all players can watch the standings change throughout the game.
8. **Next question.** The host moves the game on, and the next question appears for everyone together. This repeats until the last question.
9. **Final results.** At the end, the final leaderboard shows the winner and everyone's place.

## What makes it fun

- **Everyone plays together, at the same time.** It feels like a live quiz night, even when players are in different places.
- **It's fair.** Everyone gets the same question at the same moment and the same amount of time to answer.
- **Speed matters.** Knowing the answer is good. Knowing it quickly is better.
- **You can see who's playing.** Players always know who is in the game with them and how many opponents they face.
- **Instant feedback.** Players find out right away whether they were right and where they stand.
